Checking the editor connection…

The portfolio is live, but its GitHub editing connection has not been configured yet. No repository or credentials have been guessed or exposed.

  1. Publish this code in your own GitHub repository and confirm its production branch.
  2. Deploy the official Sveltia CMS Authenticator on Cloudflare Workers and set up a GitHub OAuth App.
  3. Set CMS_GITHUB_REPO, CMS_GITHUB_BRANCH, and CMS_AUTH_BASE_URL in your hosting environment. Keep OAuth secrets in the Worker, never here.
  4. Redeploy, then return to /admin to sign in with GitHub.
